✓ Connected to Firebase
One-time setup (~5 min):
1. Go to console.firebase.google.com → New project (or use existing)
2. In your project: Build → Firestore Database → Create database → Start in test mode
3. Go to Project settings (gear icon) → scroll to Your apps → click the </> Web icon → Register app
4. Copy the firebaseConfig object (the JSON part with apiKey, authDomain, etc.)
5. Paste it above → Connect
Your data is stored privately in your own Firebase project. Free tier covers thousands of syncs/month.
